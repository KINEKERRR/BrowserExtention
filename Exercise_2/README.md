# PixelRuler

Расширение для Chrome (Manifest V3), которое измеряет расстояние на странице двумя кликами.

## Возможности

- Клик по иконке включает режим измерения (повторный клик по иконке или `Esc` выключает его).
- Первый клик на странице задаёт начальную точку, второй — конечную.
- Между точками строится линия, а посередине показывается длина в пикселях.
- Пока режим включён, курсор заменяется на перекрестие.
- Следующий клик после построенной линии начинает новое измерение: старая линия стирается, появляется новая начальная точка.
- Линия привязана к координатам страницы, поэтому при прокрутке она остаётся на своём месте вместе с контентом.

## Установка

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `src/Exercise_2`.
4. Откройте обычную страницу (`http://` или `https://`) и нажмите на иконку расширения.

## Как это работает

1. `background.js` по клику на иконку внедряет `content.js` в активную вкладку и отправляет ему сообщение `RULER_TOGGLE`.
2. `content.js` создаёт полноэкранный оверлей в Shadow DOM, чтобы стили страницы не влияли на линейку.
3. Клики записываются в координатах документа (`clientX + scrollX`, `clientY + scrollY`), а линия и подпись перерисовываются в координатах окна. Благодаря этому измерение не «уезжает» при прокрутке.
4. Курсор задаётся через `cursor.png`, который объявлен в `web_accessible_resources`.

## Структура

```
Exercise_2/
├── manifest.json
├── background.js      # активация режима и внедрение content script
├── content.js         # оверлей, точки, линия, подпись длины
├── cursor.png         # курсор-перекрестие
└── icons/             # иконки 16/32/48/128
```

## Ограничения

- Не работает на служебных страницах (`chrome://`, `chrome-extension://`, `edge://` и т. п.).
- Для страниц `file://` нужно разрешить расширению доступ к файлам на странице `chrome://extensions`.
- Длина считается в CSS-пикселях.
