# ColorPicker

Расширение для Chrome (Manifest V3), которое определяет цвет любого пикселя на активной вкладке, копирует HEX-код по клику и запоминает последние 5 выбранных цветов.

## Возможности

- Клик по иконке расширения включает режим выбора цвета и открывает попап.
- При движении мыши рядом с курсором показывается плашка с цветом пикселя в форматах `HEX` и `RGB`.
- Клик левой кнопкой мыши копирует HEX-код пикселя в буфер обмена и сохраняет цвет.
- `Esc` выключает режим выбора.
- В попапе отображаются последние 5 цветов (самый новый — первый).
- Клик по цвету в попапе раскрывает под ним строки `HEX` и `RGB`; повторный клик скрывает их. При клике на другой цвет предыдущий блок закрывается.

## Установка

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `src/Exercise_1`.
4. Откройте обычную страницу (`http://` или `https://`) и нажмите на иконку расширения.

## Как это работает

1. `background.js` получает сообщение от попапа, делает скриншот видимой области активной вкладки через `chrome.tabs.captureVisibleTab()` и внедряет `content.js` через `chrome.scripting.executeScript()`.
2. `content.js` рисует скриншот в `canvas` и по координатам курсора читает цвет пикселя через `getImageData()`. Поэтому цвет корректно определяется в том числе поверх iframe и cross-origin контента.
3. Выбранные цвета складываются в `chrome.storage.local` (не более 5, без дублей).
4. `popup.html` / `popup.js` показывают сохранённую палитру и запускают режим выбора при открытии.

Скриншот делается в момент активации расширения. Если после активации прокрутить страницу, координаты перестанут соответствовать скриншоту — активируйте расширение заново.

## Структура

```
Exercise_1/
├── manifest.json
├── background.js      # скриншот вкладки, внедрение content script, хранение цветов
├── content.js         # canvas, определение цвета, плашка, копирование
├── popup.html
├── popup.css
├── popup.js           # палитра последних 5 цветов
└── icons/             # иконки 16/32/48/128
```

## Ограничения

- Не работает на служебных страницах (`chrome://`, `chrome-extension://`, `edge://` и т. п.).
- Для страниц `file://` нужно разрешить расширению доступ к файлам на странице `chrome://extensions`.
